# Manual test checklist

Run these inside STZ Shell:
1. `pwd` displays the current directory.
2. `ls -l` lists files.
3. `echo Hello World` prints text.
4. `ls | wc -l` tests a pipeline.
5. `cd ..` changes the shell directory.
6. `debug`, then `date`, displays debug information.
7. `safe`, then `rm sample.txt`, should be blocked.
8. `procs` lists process information.
9. `monitor` displays memory and load information.
10. `exit` closes the shell.
